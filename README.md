# Beam Legal

Static legal and support pages for the Android game **Beam** by **DyxotaGame**.

## Publish with GitHub Pages

1. Open the empty `Dyxota-Game/beam-legal` repository on GitHub.
2. Select **Add file → Upload files**.
3. Drag the contents of this folder into the upload area. Keep the `docs` folder intact.
4. Enter `Add Beam legal and support pages` in the commit message and select **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main**, folder **/docs**, and click **Save**.
8. Wait until GitHub shows the site as published.

Expected URLs:

- Home: `https://dyxota-game.github.io/beam-legal/`
- Privacy policy: `https://dyxota-game.github.io/beam-legal/privacy-policy/`
- Support: `https://dyxota-game.github.io/beam-legal/support/`

Use the privacy-policy URL in Google Play Console and in the in-game **Privacy & Data** button.
